Conexión del generador con Google Drive

Esta configuración se realiza una sola vez. Después, en cada dispositivo basta con abrir el generador y conectar la misma cuenta de Google.

  1. Crear o seleccionar un proyecto en Google Cloud Console y habilitar Google Drive API.
  2. Configurar Google Auth Platform: nombre de la aplicación, correo de soporte y audiencia. Para esta prueba personal, usar estado Testing y añadir tu cuenta como usuario de prueba. No hace falta dar acceso a todos tus archivos.
  3. Crear un cliente OAuth de tipo Aplicación web. Registrar como origen JavaScript autorizado el dominio HTTPS donde se publica el generador, sin la ruta del repositorio. Ejemplo: https://hernandop1022.github.io. Para pruebas locales, añadir el origen exacto con su puerto.
  4. Copiar únicamente el ID de cliente, terminado en .apps.googleusercontent.com, en clientId dentro de config.js. No introducir un secreto de cliente, contraseña ni token.
  5. Publicar los archivos de esta carpeta, abrir el enlace y pulsar Conectar con Google Drive. Autorizar el acceso a los archivos creados o abiertos con esta aplicación (drive.file).
  6. Importar una copia JSON de un proyecto desde Copias de seguridad. Verificar que aparezca «Guardado en Google Drive». Abrir el mismo enlace en otro dispositivo y comprobar medidas, referencias y PDF.

Qué se guarda y dónde

Los proyectos permanecen en tu Drive. El repositorio solo contiene el programa. Cada guardado significativo crea una versión recuperable por proyecto en la carpeta «Generador de ventanas - Proyectos». No se borran versiones automáticamente durante esta prueba.

La conexión de Google vence periódicamente: pulsa «Conectar con Google Drive» para renovarla. El token se mantiene solo en memoria, nunca en el repositorio ni en el almacenamiento del navegador. Hay un borrador local de rescate por cuenta cuando un envío queda pendiente; no sustituye al guardado en Drive.

Antes de cambiar de dispositivo

Comprueba el mensaje «Guardado en Google Drive». En el otro equipo, usa «Actualizar desde Drive» si la aplicación ya estaba abierta. Ante un conflicto, descarga tus cambios pendientes antes de actualizar. Si existen dos versiones simultáneas, elige cuál continuar; ambas se conservan.
